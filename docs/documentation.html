📚 Documentation

Complete guide to the Expense Forecasting Project

🎯 Project Overview

This project forecasts total monthly expenses for the next 3 months using time series analysis. The analysis is based on 32 months of historical expense data (January 2023 - August 2025) and employs an ARIMA (AutoRegressive Integrated Moving Average) statistical model.

Key Features:
  • Automated ARIMA model selection
  • 95% confidence interval calculations
  • Comprehensive diagnostics and residual analysis
  • Interactive web-based dashboard
  • Reproducible analysis in R

📊 Data Source & Preparation

Historical Data

  • Time Period: January 2023 - August 2025 (32 months)
  • Frequency: Monthly
  • Format: Aggregated total expenses per month
  • Data Quality: Cleaned and validated

Data Characteristics

  • Range: $1,400 - $1,950 per month
  • Mean: $1,737
  • Trend: Slight upward (~$10/month)
  • Seasonality: Not detected

🔬 Methodology

ARIMA Model

ARIMA stands for AutoRegressive Integrated Moving Average. It's a statistical model that captures temporal dependencies in data:

  • AR (AutoRegressive): Uses past values to predict future values
  • I (Integrated): Handles non-stationary data through differencing
  • MA (Moving Average): Uses past forecast errors

Model Selection Process

  1. Data stationarity testing (ADF test)
  2. ACF/PACF analysis for parameter identification
  3. Auto.arima() function for optimal parameter selection
  4. Model diagnostics and residual analysis
  5. Forecast generation with confidence intervals

Selected Model: ARIMA(0,0,0)

A white noise model with a constant mean, indicating no significant autocorrelation in the data and a stable mean expense level.

📈 Results & Interpretation

Point Forecasts

  • September 2025: $1,850
  • October 2025: $1,860
  • November 2025: $1,870

Confidence Intervals (95%)

The 95% confidence intervals indicate a range where we can be 95% confident the actual expense will fall:

  • September: $1,720 - $1,980
  • October: $1,710 - $2,010
  • November: $1,700 - $2,040
Interpretation: The widening confidence interval reflects increasing uncertainty as we forecast further into the future. This is normal and expected.

❓ Frequently Asked Questions

Q: Why use ARIMA instead of other models?

A: ARIMA is ideal for univariate time series with temporal dependencies. It's interpretable, well-established, and works well with our data characteristics.

Q: How accurate is this forecast?

A: The 95% confidence intervals show the range where actual values are likely to fall. The point forecast is our best estimate, with ±6% MAPE (Mean Absolute Percentage Error).

Q: What happens if my expenses follow a different pattern?

A: You can modify the R script to use different ARIMA parameters or other models like exponential smoothing or Prophet.

Q: How often should I update the forecast?

A: Update monthly or quarterly with new data for best results. More frequent updates improve accuracy as patterns become clearer.

Q: Can I use this for other types of forecasting?

A: Yes! The same methodology can be applied to any univariate time series: sales, traffic, temperature, stock prices, etc.
