Data-Driven Predictions for Financial Planning

🎯 Project Goal

Forecast monthly expenses for the next 3 months using ARIMA time series analysis on 32 months of historical data (Jan 2023 - Aug 2025).

📈 Analysis Method

AutoRegressive Integrated Moving Average (ARIMA) model with automatic parameter selection, confidence intervals, and comprehensive diagnostics.

🔧 Technologies

R programming language with tidyverse, lubridate, and forecast packages for robust statistical analysis.
